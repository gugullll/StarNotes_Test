# 注册

```                                                                                                                                                                                                               
   控制中心/命令行创建用户                                                                                                                                                                                         
      → dde-system-daemon (D-Bus: org.deepin.dde.Accounts1 / org.freedesktop.Accounts)                                                                                                                             
           ├─ 账号本体:passwd/shadow/group(/usr/sbin/useradd + PAM)                                                                                                                                                
           └─ 账号扩展属性:/var/lib/AccountsService/deepin/users/<username>                                                                                                                                        
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 本机实际文件(/var/lib/AccountsService/deepin/users/ut006525)就是典型的落脚点,INI 格式:                                                                                                                            
                                                                                                                                                                                                                   
 ```ini                                                                                                                                                                                                            
   [User]                                                                                                                                                                                                          
   XSession=treeland                                                                                                                                                                                               
   SystemAccount=false                                                                                                                                                                                             
   Layout=cn;                                                                                                                                                                                                      
   Locale=zh_CN.UTF-8                                                                                                                                                                                              
   Icon=file:///var/lib/AccountsService/icons/illustration/boat.png                                                                                                                                                
   CustomIcon=                                                                                                                                                                                                     
   GreeterBackground=file:///usr/share/wallpapers/deepin/Colorful-Abstraction03.jpg                                                                                                                                
   UUID=6dc2929d-...                                                                                                                                                                                               
   Workspace=1      
 ```                                                                                                                                                                                                               
 ### 1.2 treeland 只读                                                                                                                                                                                             
                                                                                                                                                                                                                   
 src/greeter/usermodel.cpp 用的 Dtk::Accounts::DAccountsManager(来自 dtk6 的 DSystemSettings,不是 treeland 自己的代码)只是上面那个 D-Bus 服务的客户端代理:                                                         
                                                                                                                                                                                                                   
 ```cpp                                                                                                                                                                                                            
   auto userList = d->manager.userList();          // userList()                                                                                                                                                   
   auto user = d->manager.findUserById(uid);       // findUserById()                                                                                                                                               
   connect(&d->manager, &DAccountsManager::UserAdded,   ...);  // 增量                                                                                                                                             
   connect(&d->manager, &DAccountsManager::UserDeleted, ...);                                                                                                                                                      
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 DAccountsManager / DAccountsUser 确实提供了 createUser()、setPassword()、setIconFile() 等写接口(/usr/include/dtk6/DSystemSettings/daccountsmanager.h),但 treeland 一处都没调用 —— 它只在 user.cpp 里读            
 DAccountsUser 的属性并监听 userDataChanged 做刷新。
