# 域账户

域账户的身份数据不在 /etc/passwd / /etc/shadow 里,而在 UOS 的域控客户端(UDCP)本地缓存 /var/lib/libudcp-iam/ 中;桌面个性化数据则和普通账户一样落在                               
 /var/lib/AccountsService/deepin/users/。treeland 对这两者都只读



 2. 域账户数据的四层存储                                                                                                                                                                                           
                                                                                                                                                                                                                   
 ### 2.1 服务端(真正的“数据库”)                                                                                                                                                                                    
                                                                                                                                                                                                                   
 /etc/udcp-iam.conf:                                                                                                                                                                                               
                                                                                                                                                                                                                   
 ```ini                                                                                                                                                                                                            
   [id_source]                                                                                                                                                                                                     
   source = UDCP                                                                                                                                                                                                   
   ip = udcp.uniontech.com                                                                                                                                                                                         
   port = 443                                                                                                                                                                                                      
   [offline_login]                                                                                                                                                                                                 
   enable = true                                                                                                                                                                                                   
   cache_validity = 365                                                                                                                                                                                            
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 /etc/udcp/userinfo.json:is_Domain=true,域控域名 platform-udcp.uniontech.com,terminal_name=PEC004934(终端注册标识)。客户端用 /etc/udcp/UOS_Udcp.pem + .UOS_Udcp.key + clientapi_ca.crt 做双向 TLS,携带             
 /var/lib/udcp/machine.txt 的 machine_id。                                                                                                                                                                         
                                                                                                                                                                                                                   
 /var/lib/libudcp-iam/udcp-iam-tool 里能直接看到 API:

 ### 2.2 本地离线缓存(libudcp-iam 的 userdb/groupdb)                                                                                                                                                               
                                                                                                                                                                                                                   
 ```                                                                                                                                                                                                               
   /var/lib/libudcp-iam/                                                                                                                                                                                           
   ├── userdb/                                                                                                                                                                                                     
   │   ├── ut006525.user        # -rw------- root root 1379 字节(身份+凭据缓存)                                                                                                                                    
   │   └── 24881.uid -> ut006525.user     # uid → 用户文件的软链                                                                                                                                                   
   └── groupdb/                                                                                                                                                                                                    
       ├── ut006525.group / sudo.group / udcp.group ...                                                                                                                                                            
       └── 24881.gid -> ut006525.group                                                                                                                                                                             
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 - <uid>.uid / <gid>.gid 是软链索引,libnss_udcp 靠它实现 getpwuid() / getgrgid() 反查。                                                                                                                            
 - 文件 0600 root,普通用户读不到,里面是缓存的 passwd 记录与登录所需的凭据材料(离线登录用)。                                                                                                                        
 - 缓存是“按人”生成的:本机 userdb/ 里只有 ut006525,而 busctl call ... com.deepin.udcp.iam GetUserIdList 也只返回 24881 —— 只有登录过的域用户才有本地缓存,整个域的用户目录仍在服务器上。                            
 - 负责维护缓存的是 cache-udcp.service(BusName=com.deepin.udcp.iam,Before=nss-user-lookup.target,ExecStartPre=udcp-iam-transfer),它正是 libnss_udcp / pam_udcp 的数据提供者;/var/lib/libudcp-iam/udcp-iam-tool 是  
   排障用的 curl 封装。                                                                                                                                                                                            
 - 缓存有效期由 offline_login.cache_validity = 365 控制,即断网情况下域账户最多可离线登录一年。                                                                                                                     
                                                                                                                                                                                                                   
 ### 2.3 认证(密码不在本地 shadow)                                                                                                                                                                                 
                                                                                                                                                                                                                   
 /etc/pam.d/common-auth:                                                                                                                                                                                           
                                                                                                                                                                                                                   
 ```                                                                                                                                                                                                               
   auth  [success=4 ...]  pam_deepin_authentication.so                                                                                                                                                             
   auth  [success=3 default=ignore] pam_unix.so nullok try_first_pass                                                                                                                                              
   auth  [success=2 default=ignore] pam_udcp.so try_first_pass        # ← 域账户走这里                                                                                                                             
   auth  [success=1 default=ignore] pam_winbind.so ... cached_login   # ← AD/SMB 域                                                                                                                                
   auth  requisite pam_deny.so                                                                                                                                                                                     
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 /usr/lib/security/pam_udcp.so 在线时问 UDCP 服务器,离线时校验 2.2 里的缓存。密码本身不写 /etc/shadow。                                                                                                            
                                                                                                                                                                                                                   
 这条链对 treeland 直接生效,因为 /etc/pam.d/ddm(@include common-auth)和 greeter 本地兜底用的 pam_start("login")(greeterproxy.cpp:43,/etc/pam.d/login 也 @include common-auth)都会走到 pam_udcp.so。所以无论在线    
 DDM 认证还是离线本地校验,域账户都能通过。                                                                                                                                                                         
                                                                                                                                                                                                                   
 ### 2.4 桌面个性化数据(这部分是真落盘的本地数据)                                                                                                                                                                  
                                                                                                                                                                                                                   
 /var/lib/AccountsService/deepin/users/ut006525(本机真实内容,而该用户正是域用户):                                                                                                                                  
                                                                                                                                                                                                                   
 ```ini                                                                                                                                                                                                            
   [User]                                                                                                                                                                                                          
   XSession=treeland                                                                                                                                                                                               
   SystemAccount=false                                                                                                                                                                                             
   Layout=cn;                                                                                                                                                                                                      
   Locale=zh_CN.UTF-8                                                                                                                                                                                              
   Icon=file:///var/lib/AccountsService/icons/illustration/boat.png                                                                                                                                                
   DesktopBackgrounds=...                                                                                                                                                                                          
   GreeterBackground=file:///usr/share/wallpapers/deepin/...                                                                                                                                                       
   UUID=6dc2929d-...                                                                                                                                                                                               
   Workspace=1                                                                                                                                                                                                     
 ```                                                                                                                                                                                                               
                                                                                                                                                                                                                   
 头像原图在 /var/lib/AccountsService/icons/<主题>/<id>.png。写入者是 dde-system-daemon(org.deepin.dde.Accounts1),它还有一个专用的域账户对接配置:/usr/share/dde-daemon/accounts/dbus-udcp.json →                    
 com.deepin.udcp.iam,用来把域用户的昵称/头像/策略等同步给 accounts 服务。
